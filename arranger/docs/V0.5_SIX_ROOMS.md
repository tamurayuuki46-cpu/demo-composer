# Arrangement Lab v0.5 — 6つの部屋

更新日: 2026-10-13

Arrangement Labは「自動完成」ではなく、複数候補を比較してユーザーが編曲判断を行うためのラボとして整理する。

## ① 比較試聴室
ユーザーが決めること: どの案を選ぶか。

- A/B/C・Mix比較
- 簡易ラウドネス補正
- 目隠し消去式比較
- 選択Sectionの変更パートだけ再生
- Bメロ/Prechorus → サビ連続試聴
- 比較停止

## ② ハーモニー実験室
ユーザーが決めること: 同じメロディをどう響かせるか。

既存v0.4のHarmony Lab 14手法と理論Labを継続利用する。リハモ、メロディ音の再解釈、共通音、ベース基準、解決、Voicing、内声、トップライン、浮遊などを含む。

## ③ 裏メロ・対話設計
ユーザーが決めること: 主旋律とどう関わらせるか。

既存v0.4のCounter Lab 16手法を継続利用する。スケール、音域、入り、休み、応答、モチーフ、制約、A/B分担などを含む。

## ④ 展開・密度設計
ユーザーが決めること: 曲のどこで何を際立たせるか。

既存v0.4のDevelopment Lab 15手法と連動5セットを継続利用する。サビ5案、引き算、入口/出口、落差、主役交代、ラスサビ、間奏、終わり方などを含む。

v0.5ではDrum Fill 3案 / Bass Approach 3案を実Noteとして生成してSectionへ適用可能。

## ⑤ 判断の記録と復元
ユーザーが決めること: 何を試し、なぜ選んだか。

- Section / 曲全体の判断記録
- 採用 / 不採用 / 保留 / 気になる / 制作日記
- 理由・制作メモ
- Section snapshot履歴
- 記録開始時の原案へ戻す
- 任意の過去snapshotへ戻す
- 最新300件を保持
- Arrangement Planと別のlocalStorage journalの双方で復元可能性を確保

## ⑥ DAW引き継ぎ
ユーザーが決めること: 本制作で何を実現するか。

- パート別MIDI
- 変更後Song.mid (SMF Type 1)
- 変更前Song.mid
- Demo Composerへ戻せる複製project.json
- DAW引き継ぎZIP

ZIP内容:

- Before_Source_Song.mid
- After_Arrangement_Song.mid
- Melody / Harmony / Bass / Drums / Counter MIDI
- Arrangement_Plan.json
- Demo_Composer_Project.json
- TRACK_INSTRUCTIONS.md
- SECTION_INSTRUCTIONS.md
- DAW_CHECKLIST.md
- DECISIONS.json
- COMPARE_MANIFEST.json

## 非ゴール

- DAW級Piano Roll
- Plugin hosting
- Mixing / Mastering
- 高品質音源レンダリング
- 自動で「正解」の編曲を決めること

## 互換性

- Arrangement Plan Schema 4を維持
- Demo Composer Schemaは変更しない
- 保存キー `demo-composer-arranger-v0.4` を維持し旧Planとの互換を壊さない
- 判断ログは `demo-composer-arranger-decisions-v0.5`
- 元project.jsonは破壊的変更しない

# Arrangement Lab v0.6 — 初心者一本道フロー

更新日: 2026-10-13

## 目的

Arrangement Labの機能量は維持したまま、初心者が「次にどこを触るか」で迷わないようにする。

## 初心者モード（初期ON）

基本ルートは以下の6工程だけを前面に出す。

1. 曲を読み込む
2. A / B / Cを聴く
3. 残す案を1つ選ぶ
4. Sectionを1つ調整する
5. 判断を1つ記録する
6. DAWへ書き出す

完了条件は設けない。「次へ」はいつでも進められ、「前へ」でいつでも戻れる。

画面上部には常に「次にやること」を1つだけ表示し、スマートフォン下部には前へ / 現在工程 / 次への固定ナビを表示する。

## ④ Section調整の初心者表示

初心者モードでは、まず以下だけを見せる。

- 密度
- 楽器ON/OFF
- 裏メロON/OFF
- リハモ3案

以下は隠し、「もっと試す」で開く。

- A/B/C Mix
- 目隠し比較など高度比較
- Sectionの編曲ラボ（Harmony / Counter / Development / 連動50手法）
- Drum Fill / Bass Approach実Note生成
- パート別MIDIなど詳細出力
- 端末内データ削除UI

## もっと試すモード

既存v0.5までの高度機能は削除せず、すべて表示する。

モード選択は端末内に保存し、次回起動でも維持する。初回は初心者モード。

## 空状態

④にSectionがまだ無い場合、空欄にはしない。

「まず①で曲を読み込み、②でA/B/Cを作るとSectionカードが表示される」と明示し、①へ戻るボタンを出す。

## 互換性

- Arrangement Plan Schema 4を変更しない
- 保存キー `demo-composer-arranger-v0.4` を変更しない
- 判断ログ `demo-composer-arranger-decisions-v0.5` を変更しない
- v0.6はUI導線の追加であり、既存の編曲生成・MIDI・判断履歴データは維持する
- `ARRANGER_V05_VERSION` を利用する既存データ処理は互換レイヤーとして維持する

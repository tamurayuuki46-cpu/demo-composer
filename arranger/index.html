Demo Composer companion

Arrangement Lab

1小節のフレーズからでも、複数案を鳴らして比べて編曲を試せます。

⓪ 作曲シート方向を決める ① MIDI解析任意 ② 作曲Demo Composer ③ 編曲今ここ ④ DAWへCubasis / Cubase
1

曲を読み込む

Demo Composerのproject.jsonまたはSong Project v1を使用します。元データは変更しません。

1小節だけでもOK。 Demo Composerでメロディやコードを1小節作ってSongProject v1で渡せば、Section未作成でも「1小節スケッチ」として編曲を始められます。

2

A / B / Cを聴く

Styleから3案を作り、まずは順番に簡易試聴します。

選択Sectionから最大16秒。簡易試聴はproject.jsonのコード/ノートをWeb Audioで鳴らす比較用スケッチです。

3

残す案を選ぶ

初心者モードではA/B/Cから1案を選ぶだけでOK。「もっと試す」ではMixや目隠し比較も使えます。

4

Sectionを1つ調整

まずは密度・楽器・裏メロ・リハモだけ。1小節スケッチでもこの操作を試せます。

④はまだ準備中です

まず①で曲を読み込み、②でA / B / Cを作ると、ここにSectionカードが表示されます。

5

MIDI / Project書き出し

現在選択している編曲案のON/OFFとリハモを反映します。Song Project v1から開いた場合は編曲結果だけを書き戻せます。

Song.midは採用済み編曲案を5トラック（Chords / Melody / Counter Melody / Bass / Drums）で出力します。Tempo / Time Signature / Section Markerも含みます。Song Project v1の書き戻しはarrangement領域だけを更新し、Demo Composerのcompositionは上書きしません。

端末内データ

採用した編曲プランだけを消去します。Demo Composerの曲は消しません。

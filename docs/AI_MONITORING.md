# AIモニタリング

Version: v0.15-dev
更新日: 2026-10-14

## 目的

Demo Composer 内の使い方を端末内で記録し、機能の利用傾向から次の3点を分かりやすく返す。

- ポジティブフィードバック
- ネガティブフィードバック（改善ポイント）
- 次に試す使い方

あわせて、主要機能全体の使用済み率・未使用率を百分率で表示し、未使用機能を一覧できるようにする。

## 記録範囲

`src/hub/ai-monitoring.js` が主要32機能の操作をイベント委譲で記録する。

記録するもの:

- 使った機能ID
- 使用回数
- 最終使用時刻
- セッション数

記録しないもの:

- MIDI本体
- 音声
- 曲のノート内容
- Project JSONの中身
- 個人情報

記録先はブラウザの `localStorage` (`demo-composer.ai-monitoring.v1`) のみで、外部送信しない。

## 表示

Hub に「AIモニタリング」カードを挿入する。

- 使用済み率 / 未使用率
- 使用済み機能数 / 全32機能
- カテゴリ別利用率
- ポジティブフィードバック
- ネガティブフィードバック
- 次に試す未使用機能 1〜3件
- 未使用機能の全一覧

## 判定方針

使用率は「主要機能を一度でも使ったか」を基準にする。特定機能を大量に連打しても使用率は上がらない。

提案は未使用機能から、作曲 → アレンジ → 試聴 → 補助 → 入出力 → 仕上げ → 基本の順を基本優先度として最大3件出す。

## プライバシー

AIモニタリングはローカル分析型。外部APIや生成AIへの送信を必要とせず、オフラインでも集計・提案できる。

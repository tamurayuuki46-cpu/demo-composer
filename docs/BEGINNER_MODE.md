# Beginner Mode

Demo Composerの初心者導線は「触る順番が迷わないこと」を最優先にする。

## 基本方針

- 初心者モードは既定ON。
- 完了条件は設けない。いつでも「次へ」で進める。
- 「仮決めでOK。あとから戻って直せる」を常に明示する。
- 基本ルートは `準備 → コード → メロディ → リズム → 構成 → Arrangement Lab`。
- 作曲シートはDemo Composerより前、Arrangement LabはDemo Composerより後の工程として案内する。
- 初心者モード中は、基本ルート外の `裏メロ` と `Sound` を通常時は隠す。
- `もっと試す` を開いた時だけ、追加機能への入口を見せる。

## もっと試す

各工程で候補は5つまでに固定する。候補を大量表示して判断を増やさない。

- Hub: BPM/Key仮決め、作曲シート見直し、MIDI取込、AI相談、音色先行
- Chord: 王道、J-POP切ない、次コード、メロディからコード、変化球
- Melody: 安定、キャッチー、浮遊感、4小節、リズム変更
- Rhythm: 8ビート、4つ打ち、Pop、Rock、Half Time
- Arrange: A→B→サビ、Intro、サビ前の落差、裏メロ、音色

## UX原則

初心者モードは機能削除ではなく案内レイヤー。既存機能は維持し、通常モードまたは「もっと試す」からアクセスできる。完成度を要求して進行を止めるゲートは作らない。

# Counter Melody 4 Styles

更新日: 2026-10-11
対象Version: v0.2-dev

## 目的

Arrange の裏メロ候補を、役割が分かりやすい4系統へ整理する。

完成フレーズを自動作曲する機能ではなく、Sectionごとに4つを聴き比べて選び、必要なら別候補へ替えるための叩き台とする。

## 6系統

### Sparse（隙間型）

- メインMelodyの休符・隙間を優先する
- 音数は少なめ
- 短いレスポンスを中心にする
- メインMelodyが詰まった小節では無理に入れない
- ※イメージ: 米津系。特定曲のコピーや旋律再現ではなく「隙間を使う役割」の参考分類

### Active（動く型）

- 8分音符中心
- メインMelodyより下側を基本にする
- 土台のコード進行自体は変えない
- 1小節の中で、次の3つの色を順番に混ぜる
  1. コードトーン型: 強拍を中心に現在コードの構成音で安定させる
  2. テンション型: 現在Key内のコード外音を使い、9th / 11th / 13th系の色を足す
  3. 薄い別コード感型: 現在コードの3度上のScale Degreeから作る3音を薄く重ね、第二のハーモニーの輪郭を作る
- 例: C Major上のCコードなら、薄い別コード感型では E-G-B の輪郭を使える。土台はCのままなので、Emへ転調・コード変更するわけではない
- 主旋律と同じ音をなぞるのではなく、主旋律とは違うDegreeを選んでコードの色と推進力を足す
- ※イメージ: YOASOBI / Ayase系。特定曲のコピーや旋律再現ではなく「動きながら第二のハーモニーを薄く作る役割」の参考分類

### Hook（フック型）

- 少ない音で覚えやすい輪郭を作る
- 同じリズム形を小節ごとに繰り返す
- コードが変わっても「上がって戻る」輪郭を保つ
- もう1つの歌えるフックとして使う
- ※イメージ: Oasis系。特定曲のコピーや旋律再現ではなく「反復フックの役割」の参考分類

### Answer（応答型）

- メインMelodyの語尾や小節後半の空きを優先する
- Sparseより音価を長めにし、短い装飾より「歌への返答」を感じる形にする
- ルートより3度・7度など、コードの明暗や色が出やすい音を優先する
- 4つ空きstepがある場合は2音を2stepずつ置き、少し上がる / 下がる流れで感情を補強する
- 主旋律が詰まっている小節では無理に入れない
- ※イメージ: Mr.Children系。特定曲のコピーや旋律再現ではなく「歌の語尾に応答して感情を補強する役割」の参考分類

### Arpeggio（分散和音型）
- 現在のコードの構成音を、メインメロディの下の音域で8分音符の上下に流す（ピアノ風）
- メロディが裏拍から始まるマスは休み、半音でぶつかる音・メロディに近すぎる音は休む。メロディが鳴っている間は少し小さく
- 小節の最後は、次のコードの構成音へつなぐ
- 参考イメージ: ピアノが走るYOASOBI / Ayase系（特定曲のコピーではない）

### Riff（ギターリフ型）
- 低い音域で、ルート・5度中心の短いリフ（半小節の形を2回）。コードが変わっても形は同じで、音だけ移る
- 小節の最後は次のルートへのつなぎ。4小節ごとの4小節目は、ルートから1音ずつ駆け上がる
- メインメロディには依存しない（コードだけで作れる）
- 参考イメージ: ギターバンド系 / Oasis系（特定曲のコピーではない）

## 使い分けの目安

- Sparse = 隙間を短く埋める
- Active = 主旋律の下で動き続ける
- Hook = 反復するもう1つのフックを作る
- Answer = 主旋律が言い切った後に、少し長めに返す
- Arpeggio = コードの構成音を細かく流して、曲全体を前へ進める
- Riff = 低い音域の繰り返しで、土台の勢いを作る

Sparse と Answer はどちらも休符を使うが、Sparse は短い装飾、Answer は語尾への応答という役割で分ける。

## 7–8. Minor Penta Hook / Major Penta Hook

- Keyのペンタトニック（マイナー: 0,3,5,7,10 / メジャー: 0,2,4,7,9）の音だけを使う。ペンタの音を「はしご」にして上下に動く。
- 2小節同じ型 → 3小節目で変化 → 4小節目（と範囲の最後）の最後の音はコードトーンに着地。
- 音域は MIDI 48〜79、メロディ平均の約10半音下を狙う。メジャーKeyでマイナーペンタを使うとブルース寄りの色になる。

## 9. Character（特性音型）

- 特性音 = 選んだスケールが、近い基本スケール（長3度があればMajor、短3度ならNatural Minor）と違う音。違いが無いスケール（ペンタなど）はルートと5度以外の音を特性音とする。
- 4小節の流れ: ① 助走→特性音(長)→ルート/5度 ② 特性音→上の隣→特性音→着地 ③ 強拍の特性音を食い気味に ④ 特性音を長く→ルートに解決。特性音が複数あるスケールは、フレーズごとに主役が変わる。
- 音はすべて選んだスケール内。コードと半音でぶつかる所は「スケールの色」として耳で確かめる（衝突回避は未実装）。
- スケールは裏メロタブで選ぶ（画面の状態で保存しない）。Arrangeの裏メロは未選択（Dorian / Lydian）で作る。

### Character: スケール別の型

- `src/core/character-phrases.js` に、スケールIDごとの4小節（①提示 ②返し ③高まり ④解決 / 浮かせる）を持つ。音程は主音からの半音数、stepは8分単位（小数可）。
- 型があるのは 20 スケール（Dorian / Phrygian / Lydian / Mixolydian / Locrian / ハーモニック・メロディックマイナー / Phrygian Dominant / Double Harmonic / Hungarian Minor / ホールトーン / ディミニッシュ(WH・HW) / ブルース / Lydian Dominant / Altered / 都節音階 / 陰旋法 / 律 / 琉球）。それ以外は従来の共通型（助走→特性音→ルート/5度）。
- 型を足すときは、音程がスケール内であること、特性音が長い音にあること、4小節がすべて違うことをテスト（`test:counter-melody`）が確認する。

## 10. Motion（対位の動き）

- 反行: 主旋律が動いた向きと逆へ、同じ程度（最大3スケール音）動く。小節の頭はコードトーンへ寄せ、常に主旋律の3半音以上下に置く。
- 平行: 主旋律の各音を、Key内の3度下でなぞる（ハモリ）。
- 保続: 主音（Key）を低音域で2小節ずつ持続（ペダルポイント）。コードが変わっても動かない。メロディが無い範囲でも作れる。
- 反行 / 平行はメロディが無い範囲では置ける場所がない。Arrangeの裏メロは反行で作る。

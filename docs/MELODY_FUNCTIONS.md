# MELODY_FUNCTIONS

## 目的

Melody Analyzerで、メロディを単に「コードトーンかどうか」だけでなく、

1. コードに対して何の音か
2. 前後の音との関係でどう働いているか
3. フレーズ素材として何を意識するとよいか

の3層で理解できるようにする。

良い / 悪いを採点する機能ではない。初心者〜初中級者が、自分のメロディを観察して修正するための学習補助とする。

## 1. 和声での役割

Melody Analyzerに次の内訳を表示する。

- `Guide`: コードトーンのうち3rd / 7th系
- `Chord`: コード構成音
- `Tension`: コード外の9th / 11th / 13th相当（初期版は自然テンションのみ）
- `Other`: 上記以外の非和声音

`Guide` は `Chord` の一部なので、GuideとChordの数は足し合わせない。

目的は「安定音 / コードの性格を決める音 / 色を加える音」を区別して見ること。

## 2. 非和声音・Melodic Function

前後関係が明確な場合だけ、次をルールベースで検出する。

- 経過音（Passing Tone）
- 刺繍音（Neighbor Tone）
- アプローチノート（Approach Note）
- 倚音（Appoggiatura）
- 逸音（Escape Tone）
- 先取音（Anticipation）
- 係留音候補（Suspension candidate）

### 判定方針

誤判定を減らすため、初期版は保守的に判定する。

- 経過 / 刺繍 / Approach / 倚音 / 逸音は、原則として同じ小節・同じChord内の前後3音を見る
- 経過音は、2つのコードトーンを同方向の半音 / 全音進行でつなぐ非和声音
- 刺繍音は、同じコードトーンから半音 / 全音で外れて元の音へ戻る非和声音
- 倚音は、跳躍で非和声音へ入り、半音 / 全音でコードトーンへ解決する型
- 逸音は、コードトーンから半音 / 全音で外れ、反対方向へ跳躍する型
- Approachは、次のコードトーンへ半音 / 全音で接近する非和声音で、上記の明確な型に当てはまらないもの
- 先取音は、小節終盤で現在Chordでは非和声音、次Chordではコードトーンになる音
- 係留音候補は、前Chordのコードトーンを小節線を越えて保持し、次Chordでは非和声音になる音

係留音は本来「保持 → 不協和 → 解決」まで含めて判断する概念だが、v0.2ではNoteの保持関係までを見て「係留音候補」として扱う。将来、解決音まで安全に判定できる場合のみ精緻化する。

## 3. フレーズ語彙

Melody Analyzerには学習ガイドとして次を表示する。

- モチーフ: 曲の核になる短い音型
- リック: 使い回し可能な短いフレーズ語彙
- リフ: 曲中で反復され、特徴として聞こえるパターン
- シーケンス: 音型を保ちながら高さを変えて反復する手法

### 自動判定しないもの

`リック` と `リフ` は文脈・反復・ジャンル語彙への依存が大きいため、v0.2では自動判定しない。

既存の `モチーフ反復` は小節単位の同型反復として継続利用するが、それを自動的に「リック」「リフ」と断定しない。

## 実装

- `src/core/melodic-functions.js`: 和声役割 / 非和声音の働きを純粋計算
- `src/core/melody-analysis.js`: 既存Melody Analyzerへ表示行を統合
- `src/melody/melody-screen.js`: 既存のAnalyzer行レンダリングをそのまま利用
- `scripts/melody-analysis-smoke-test.mjs`: 各代表パターンを検証

## Data / Schema

分析結果は保存しない。

現在の `project.json` のChord / Melody Noteを読み、画面表示時に毎回計算する。

- schemaVersion: `2` のまま
- Migration: 不要
- MIDI Export: 変更なし
- Melody Note Data: 変更なし
- Melody候補生成: 変更なし
- AutoSave / Undo / Redo: 変更なし

## UX方針

新しい独立ModuleやDAW級編集機能は増やさない。

既存のMelody Analyzer内に表示し、ユーザーが

`Chordとの関係 → 音の働き → フレーズの考え方`

の順に理解できるようにする。

分析は「正解判定」ではなく、作曲判断の材料として提示する。

# 4小節メロディ生成（Chord画面）と今後の拡張

最終更新: 2026-10-12

## 目的

「PCを起動する前に、メロディの骨格をスマホで決める」ための、フレーズ単位（2 / 4 / 8小節）の生成。
完全自動作曲ではなく、**3候補を聴く → 選ぶ → Piano Rollで直す** を基本にする。
ブレスト（2026-10-12）で出たアイデアのうち、まず土台（A）を実装し、B以降は土台に重ねる。

## 実装済み（v0.2-dev）: A. フレーズの骨格

- 場所: Chord画面の `🎤 4小節メロディをつくる`（`src/melody/phrase-generator.js` / `phrase-melody-ui.js`）
- 範囲: 開始小節 + 長さ（2 / 4 / 8小節）。曲のコード数を超えない。コードが無ければ作れない
- 輪郭: `おまかせ / 上行 / 下降 / 平坦`。おまかせは候補ごとにその型に合う形
- 3つの型（候補）:
  - モチーフ反復型: 短い音型を作り、高さをずらして繰り返す。最後はコードトーンで着地
  - 問いと答え型: 前半は“問い”で浮かせたまま止まり（コードトーンでもアボイドでもないスケール音）、後半で答えて着地
  - ピーク型: 音数と高さが増え、後ろから2小節目で頂点、最後に着地
- 生成の規則（説明可能なルールのみ。外部AI / APIは使わない）:
  - 音はすべて曲のKey / Scale内。小節の頭と最後の着地音はその小節のコードトーン
  - 強拍・長い音は近くのコードトーンへ寄せる
  - 小節の最後の音は、次の小節の頭の音の隣（コード変わり目への着地）。問いの小節だけ浮かせる
  - 上行 / 下降は、小節の頭の音が必ず前の小節より先へ進む
  - `↻ 候補を更新` で4つのモチーフを順番に切り替える（UI状態のみ）
- 保存: 範囲内のMelodyだけを通常の `tracks[role=melody].notes[]` として置き換える（Schema変更なし、1回の編集 = ↶で戻せる）。Chordは変えない
- 試聴: 範囲だけ仮に当てて再生（Projectは変更しない）

## 次の候補（優先順）

1. **B. 味付けの選択**（✅ 実装済み: `ふつう / 2度・6度 / 高密度`）（土台に「味付け」を1つ渡す）
   - 2度・6度を多用するパターン（浮遊感・ペンタ寄り）
   - YOASOBI風（参考イメージ。特定曲のコピーではない）: 16分を含む高密度リズム、拍の裏から入る先取り、同音連打 → 跳躍、サビ前に音域を上げる、コードトーンの間をスケール音で埋めて細かく上下する
2. **C. 裏メロの新しい型**（✅ ピアノ風の分散和音 `Arpeggio` とギターリフ `Riff` は実装済み。対位法の動きの選択も ✅ 実装済み: Motion 反行 / 平行 / 保続）（既存のSparse / Active / Hook / Answerに追加。Arrangeの各Sectionで）
   - ピアノ風の分散和音（メインの休符を読み、隙間を走る。上行・下行・往復・3音ずつ）
   - オアシス風のギターリフ（参考イメージ。短いリフを繰り返し、コードが変わっても形を保つ。ルート・5度・オクターブ中心の低めの音域）
   - 対位法の動きの選択（✅ 実装済み: 反行・平行・保続）
3. **D. スケールの色違い**（✅ 実装済み: Chord画面の `スケールの色` セレクト）: 「スケール系のコード」で増やしたスケール（スパニッシュ・ペンタ・都節など）の音で、同じ型の候補を並べて聴き比べる
4. エネルギーとの連動: Arrangeのエネルギー（ピークの度合い）で音域とリズム密度を変える

## 判断基準

「この機能でスマホ上の作曲判断がしやすくなるか？」。候補は3つまで、選ぶ負担を増やさない。

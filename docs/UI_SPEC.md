# UI_SPEC

## 対象
Androidスマホ / Chrome / PWA。片手操作を優先する。

## Chord Module: 曲想タグ連携

### 入力
- タグはチップ形式で選択
- 3カテゴリ: 感情 / 質感 / 場面
- 最初は各カテゴリ5〜8個程度だけ表示し、増やしすぎない
- 複数選択可

### 候補表示
選択タグから最大3案をカード表示する。

各カードには以下だけを表示する。
- Degree進行
- Keyに変換したコード名
- 相性の高いタグ2〜3個
- 難易度: 王道 / 少し個性的 / 挑戦的
- 試聴ボタン（後続実装）
- この進行を使うボタン

### 注意表示
「同じコード進行でも、メロディ・BPM・リズム・ボイシング・音色で印象は変わります」を小さく補足する。

## 操作原則
- 小さすぎるタップ領域を使わない
- 横スクロールを前提にしない
- 長押しを必須操作にしない
- 主要アクションは画面下側に置く

# UI_SPEC

## Target

Android Chrome / Android smartphone.

## Global Rules

- 片手操作を優先
- タップ領域は大きく
- 小さすぎる文字を使わない
- 横スクロールを減らす
- 長押し依存を避ける
- 重要操作を画面下部へ寄せる
- PC DAWを縮小したUIにしない

## v0.1 Navigation

Bottom Navigation:

- Hub
- Chord
- Melody
- Rhythm

## Hub

表示:

- Project名
- BPM
- Key
- Scale
- 進捗
- Save
- Export
- AI相談

## Chord

- コードカード
- Degree併記
- 候補3つ
- 追加 / 並べ替え / 削除

## Melody

- スマホ向け簡易Piano Roll
- Scale表示
- Chord Tone強調
- Analyzerは同画面パネル

## Rhythm

- Bass / Kick / Snare / Hi-Hat
- BassとKickを同時確認
- 16 Stepを基本

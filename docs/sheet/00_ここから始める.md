# ここから始める(一本道)

作曲を始めるときは、まずこのタブだけを見ます。ほかのタブは「必要になったとき」の資料です。全部を開く必要はありません。

やることは6つのステップです。目安は、全部で1時間前後です(Demo Composerで鳴らす時間を含みます)。

Demo Composerを開く: [Demo Composer(アプリ)](https://tamurayuuki46-cpu.github.io/demo-composer/)(スマホのChromeで開き、「ホーム画面に追加」しておくと便利です)

## ルール

- 1つのステップで15分以上止まったら、そのステップは空欄のまま、次へ進む
- 空欄は「まだ決めない」の意味です。あとで戻って直してかまいません
- 各ステップの最後にある、Demo Composerでの操作まで進めて、一度鳴らす

## ステップ1:テーマ・場面・心情を拾う(5分)

- [ ] 開くタブ:「テーマ・場面・心情」(`02_テーマ・場面・心情.md`)
- [ ] テーマ・場面・心情を、それぞれ1つずつ選ぶ(自分の言葉で書いてもよい)
- [ ] 選んだ言葉を、記入シートの「曲全体」に書き写す:「[Claude] 作曲シート(記入用)」(`01_作曲シート_記入用.md`)

- ゴール:「どんな曲か」を、一言で言える

ステップ1の補助(任意):コンセプトの文章を、Demo Composerの設定に近づけたいときは、「コンセプトの橋渡し」(`00b_コンセプトの橋渡し.md`)を開く

## ステップ2:ジャンルと参考曲を決める(5分)

- [ ] 開くタブ:「ジャンルリスト」(`06_ジャンルリスト.md`)
- [ ] ジャンルを1つ選ぶ(迷ったら、ステップ1の心情に近いもの)
- [ ] 近い曲を1〜3曲だけ、記入シートの「参考曲」に書く(困ったら:「参考アーティスト」(`05_参考アーティスト.md`))

- ゴール:「この曲に近い」と言える1曲がある

## ステップ3:Keyを決めて、Demo Composerで鳴らす(5分)

- [ ] 開くタブ:「キー早見表」(`03_キー早見表.md`)
- [ ] 迷ったら、C(または Am)から始める
- [ ] Demo Composerを開き、Hubの「出発点」で、雰囲気・テンポ・聴かせ方の3問に答える
- [ ] 出てきた3つの候補を聴き、1つ選んで適用する

- ゴール:仮のコード進行とドラムが鳴っている

## ステップ4:サビを先に作る(15分)

- [ ] 開くタブ:「アイデア帳」(`04_アイデア帳/`、フックの引き出しを見る)
- [ ] 記入シートの「サビ」の欄に、コード・メロ・ベース・ドラムの方向を、1行ずつ書く
- [ ] Demo Composerの、ChordとMelodyで、サビ部分の1小節か2小節を作る

- ゴール:サビの頭の1フレーズが、口ずさめる

## ステップ5:構成と山谷を決める(10分)

- [ ] 開くタブ:「構成ストック」(`08_構成ストック.md`)、「[Claude] 作曲シート(記入用)」(山谷の表)
- [ ] 構成の型を1つ選び、各セクションの盛り上がりを、低・中・高で選ぶ
- [ ] Demo Composerの、Arrangeで、セクションを並べる

- ゴール:曲の最初から最後までの流れが、数字で見える

## ステップ6:肉付けと、仕上げの確認(15分)

- [ ] 開くタブ:「アイデア帳」(ベース・ドラム・裏メロの引き出し)
- [ ] Demo Composerの、Rhythm、Soundで、ベースとドラム、音色の方向を決める
- [ ] 一度通して聴き、「いい曲チェック」(`09_いい曲チェック.md`)で、一番低い項目を1つだけ直す
- [ ] Song.mid と、パートごとのMIDIを書き出し、Cubasis / Cubaseへ渡す(DAWでやる項目は:「DAWに任せる項目」(`10_DAWに任せる項目.md`))

- ゴール:Demo v1が書き出せる

## 詰まったときだけ開くタブ

- 用語で点検したい:「理論チェックリスト」(`07_理論チェックリスト.md`)
- アイデアが出ない:アイデア帳の各サブタブ
- 好きな人の手法を借りたい:参考アーティストのタブ

## 終わったら

- [ ] 次の曲では、使わなかったステップに「なぜ使わなかったか」を一言メモした
- [ ] 時間がかかったステップがあれば、次回は、そのステップだけ簡単にした

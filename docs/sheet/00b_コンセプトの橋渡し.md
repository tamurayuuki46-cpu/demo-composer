# コンセプトの橋渡し

言葉でコンセプトを書いたあと、Demo Composerの設定に近づけたいときの、Claude(またはChatGPT)への頼み方です。「ここから始める」のステップ1のあとで使います。任意です。

## 使い方

1. 下の文章をコピーして、Claude(またはChatGPT)に貼る
2. カッコの中を、自分の曲の言葉に書き換える
3. 返ってきた3つの候補から、自分で1つ選ぶ

```text
曲のコンセプトを、Demo Composerの設定に近づけたいです。

【コンセプト】
テーマ:(例:孤独は悪くない)
場面:(例:終電後に一人で歩く帰り道)
心情:(例:寂しいけど軽い)
ジャンルのイメージ:(例:J-POP、バラードなど。なければ空欄)
参考にしたい曲:(例:あれば1〜3曲。なければ空欄)

【出してほしいもの】
1. Demo Composerの出発点(王道ポップ、切ないポップ、J-POP王道(切ない)、やさしいポップ、夜のチル、やさしいバラード、切ないバラード、夜のバラード、ストレートなロック、ダークなロック、明るい4つ打ち、夜の4つ打ち、疾走する切なさ、明るい高速ポップ)から、近い順に3つと、それぞれの選んだ理由
2. その3つに合う、Keyの案と、BPMの目安
3. サビ、Aメロ、Bメロの盛り上がりを、低・中・高で表した山谷の案(3パターン)
4. サビの頭のフックの案(3つ。短い言葉で)
5. 今回挑戦する作曲技法を、1つだけ(初心者向けのもの)

【お願い】
- 1つに決めず、必ず3つの候補で出してください
- 理由は、1行ずつ、やさしい言葉で書いてください
- 分からない点があれば、最後に質問を2つまで出してください
```

## 確認

- [ ] 返ってきた3つの候補から、1つを自分で選んだ(全部を採用しなくてよい)
- [ ] 選んだものを、記入シートの「曲全体」と「山谷」に書き写した
- [ ] Demo ComposerのHubで、同じ名前の出発点を選んで、鳴らしてみた

これは、自然言語で書いたコンセプトを、アプリの設定につなぐ「橋」です。判断をClaudeに任せきりにせず、候補から選んで、自分で直す流れにしています。

出発点の名前は、Demo Composerのコード(starting-point.js)にある14種類です。出発点が増えたときは、上の文章の一覧も更新してください。

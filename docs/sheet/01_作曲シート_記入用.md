# [Claude] 作曲シート(記入用)

2026-10-12 · たむらゆうき

Aメロ〜Dメロの山谷、パート別の参考フレーズ、曲全体のテーマ、場面と心情を、ざっくり一言ずつ決めるためのシートです。全部を埋める必要はありません。

## 使い方

上から順に書きます。目安は10分です。

1. 曲全体(テーマ・場面と心情)を、各1行で書く
2. 山谷は、タップして選ぶだけ
3. サビのパート別の欄から先に書き、他のメロは後回しでよい

空欄は「まだ決めない」の意味です。参考フレーズは曲名のコピーではなく、**特徴を言葉で**書きます(例:「隙間の多いピアノ」)。

## 山谷

曲全体を通して、どこが静かでどこが最大かを選びます。サビを「高」にして、他を相対的に決めるのがおすすめです。

| メロ | 盛り上がり | この部分の一言 |
|---|---|---|
| Aメロ | 低 / 中 / 高 | |
| Bメロ | 低 / 中 / 高 | |
| サビ | 低 / 中 / 高 | |
| Cメロ | 低 / 中 / 高 | |
| Dメロ | 低 / 中 / 高 | |

Cメロ・Dメロを使わない曲は、その行を空欄のままにします。

## 書き終えたら

- [ ] 曲全体の「テーマ」と「心情」が1行ずつ埋まっている
- [ ] 山谷で「高」がサビだけ、または意図した場所だけになっている
- [ ] サビのパート別に、1つ以上書けている
- [ ] 全部の空欄は埋めていない(それでよい)

Demo Composerへは、この内容を見ながら出発点の質問に答えます。雰囲気・テンポ・聴かせ方の3問は、ここで書いた「心情」と「山谷」から選べます。

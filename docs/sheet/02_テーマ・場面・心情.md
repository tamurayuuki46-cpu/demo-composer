# テーマ・場面・心情リスト

曲を始める前に、「何を伝えるか」「どこの場面か」「どんな気持ちか」を拾うためのストックです。ここから**1つずつ拾って**、1枚目の記入シートの「曲全体」に書き写します。選ばなくても、自分の言葉で書いて構いません。

## テーマ(曲が伝えたいこと)

| 分野 | 例 |
|---|---|
| 恋・人間関係 | 片想い、失恋、再会、すれ違い、未練、感謝 |
| 自分自身 | 孤独、劣等感、自己肯定、成長、変化への恐れ |
| 人生の節目 | 旅立ち、別れ、後悔、希望、再出発 |
| 社会・日常 | 日常の違和感、都会、働くこと、SNS、正解がないこと |
| 世界観・概念 | 夢と現実、夜と朝、季節の移ろい、記憶、時間の流れ |
| 戻らないもの | 子どもの頃、あの夏、終わった関係、失った場所 |

## 場面(いつ・どこで・誰が)

| 分野 | 例 |
|---|---|
| 時間帯 | 朝、昼休み、夕暮れ、夜、深夜、始発、終電後 |
| 場所 | 駅、帰り道、海沿い、屋上、部屋、教室、街の雑踏 |
| 季節・天候 | 春の始まり、夏の終わり、秋の夜、冬の朝、雨の日、雪の朝 |
| 状況 | 一人で歩く、電車で外を見る、返事を待つ、荷物をまとめる、最後の日 |
| 視点 | 一人称(僕・私)、誰かへの手紙、起こったことを振り返る |

## 心情(形容詞でよい)

| 方向 | 例 | Demo ComposerのMood |
|---|---|---|
| 切ない系 | 寂しい、切ない、さみしい、未練、ほろ苦い、懐かしい | 切ない |
| 明るい系 | 前向き、爽やか、軽い、期待、わくわく | 明るい |
| 静かな系 | しっとり、落ち着く、内省、やさしい、のんびり | やさしい |
| 夜の系 | 静か、ひとり、ゆらゆら、とろける、深い | 夜 |
| 力強い系 | 燃える、焦り、怒り、決意、押し出す | 力強い |
| 複雑な系 | 寂しいけど軽い、笑いながら泣く、不安だが進む、あきらめと期待 | 近いものを選ぶ |

「複雑な系」は、反対の気持ちを2つ混ぜると、曲に奥行きが出ます。Moodの選択肢(切ない・明るい・夜・力強い・やさしい)は5つなので、一番近いものを選び、細かいニュアンスは「場面」と「心情」の言葉で残します。

## 組み合わせ例(叩き台)

こちらで用意した例です。「近い出発点」は、Demo Composerの出発点の名前です。

| テーマ | 場面 | 心情 | 近い出発点 |

# キー早見表

12個のKeyの大雑把なイメージです。同じメロディでも、Keyを変えると音の高さと楽器の鳴り方が変わり、印象が変わります。ここに書いたものは絶対の性格ではなく、**楽器の鳴りや声の高さから来る傾向**の目安です。

## 選び方の大原則

- **歌う人の声域を先に見る**:サビの最高音が無理なく出るようにKeyを決める(これが最優先)
- メジャーと、同じ調号を持つマイナー(並行短調)は、使う音が同じ
- 迷ったら、まず基準のC / Amで作って、あとからKeyを移調する(Demo Composerは、Key変更でChord / Melody / Bassをまとめて移調できる)

## 12Keyのイメージ

| Key(メジャー) | 並行短調 | 大雑把なイメージ | よく合う場面 |
|---|---|---|---|
| C | Am | 素直、基準、飾り気がない | ピアノで弾き語り、試作の出発点 |
| D♭(C#) | B♭m | やわらかく、しっとり、少し暗め | ピアノのバラード、低い声 |
| D | Bm | 明るく、華やか、張りがある | ギターが鳴りやすい、ポップス・ロック |
| E♭(D#) | Cm | 落ち着いた、重さがある、ややクラシック | 管楽器・ブラス、ストリングス |
| E | C#m | 輝く、力強い、ギラッとした | ロック、ギターサウンド |
| F | Dm | やさしい、温かい、落ち着く | バラード、ゆっくりした曲 |
| F#(G♭) | D#m(E♭m) | 派手、張りつめた、緊張感 | シンセ、ピアノ。ギターは弱い |
| G | Em | 爽やか、素直、親しみやすい | ギター、フォーク、J-POPの定番 |
| A♭(G#) | Fm | 温かい、少し切ない、しっとり | バラード、シャッフル、ピアノ |
| A | F#m | 明るく開放的、すっきり | ロック、ポップス、ギター |
| B♭(A#) | Gm | 落ち着いた、深み、大人っぽい | ジャズ、ブラス、ボーカロイドもここが多い |
| B | G#m | 鋭い、張りがある、緊張 | シンセ、エッジの利いた曲 |

## 確認チェック

- [ ] 歌う人の声域(低い音と高い音)を先に確かめた
- [ ] サビの最高音が、無理なく出る高さになっている
- [ ] 仮のKeyで作って、Demo Composerの移調で、他のKeyを試した
- [ ] 黒鍵の多いKeyを選んだとき、使う楽器で弾きやすいか確かめた

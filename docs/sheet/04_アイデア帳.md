# アイデア帳

作曲中に「具体的に何をするか」で詰まったときの引き出しです。パートごとに、すぐ試せる形で書きました。引き出しは、このタブの下にあるサブタブに分かれています。使うものだけ開けば、ほかは閉じたままにできます。

注意:この帳面は、最初から完成しているものではありません。曲を作りながら、**気づいたネタを、各サブタブ(各タグ)の中に増やしていく**使い方を推奨します。自分で足してもよく、Claudeに頼んで足してもらってもかまいません。増えるほど、自分専用の引き出しになります。

## 使い方

- 各サブタブには、表が1つあります。見たい引き出しのサブタブだけを開く
- 自分で足すとき:表の最後にある「自分」の空欄の行に書き込む。行が足りなければ、表の最後の行で行を追加する
- Claudeに足してもらうとき:「アイデア帳の○○に、△個足して」と頼む。Claudeが表の最後に行を足し、「出どころ」の列に「Claude」と書く
- 「出どころ」の列:Claude=Claudeが書いた案(聴いて確かめる前のもの)、自分=自分で足したもの、曲名など=参考にした曲
- 引き出しそのものを増やすとき:「アイデア帳に『○○』の引き出しを足して」と頼む。新しいサブタブが、このタブの下に増える

## 貯めるときのチェック

- [ ] 気に入った形は、「中身」を具体的に書いた(リズムの並びか、数字)
- [ ] 使った曲と、使った場所(Aメロ、サビなど)を、メモした
- [ ] 合わなかったものにも、「なぜ合わなかったか」を一言書いた
- [ ] 1曲では、各パート1〜2個に絞って使った

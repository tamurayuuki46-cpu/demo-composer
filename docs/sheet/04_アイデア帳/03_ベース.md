# ベース

Demo Composerにあるもの:ルート型 / リフ型 / ファンク型 / シンセウェーブ型 / 裏メロ型

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| ルート全音符 | ルートを1小節、伸ばす | イントロ、バラード | Claude |
| ルート8分 | ルートを8分で刻む | ロック、疾走系 | Claude |
| ルート+オクターブ | 8分で、2拍裏と4拍裏だけ1オクターブ上 | ポップス、ダンス | Claude |
| ルート→5度 | 1拍目はルート、3拍目は5度(4分) | カントリー、落ち着いた曲 | Claude |
| キックに合わせる | ベースの音を、キックの位置にそろえる | ロック、4つ打ち | Claude |
| 裏から入る | 休符のあと、拍の裏でルートを鳴らす | シンコペのあるポップ | Claude |
| アプローチで次へ | 小節の最後に、次のルートへ半音下から入る | コードが変わる所 | Claude |
| ウォーキング | 4分で、コードトーンと経過音を並べる | ジャズ、シティポップ | Claude |

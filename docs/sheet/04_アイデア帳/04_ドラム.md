# ドラム

Demo Composerにあるもの:Drum Preset(8ビート基本 / 4つ打ち / Pop / Rock / Half Time / 16分HH)

読み方:1小節を16に分け、`x` が鳴らす位置、`.` が休みです。4つごとに1拍です。K=キック、S=スネア、HH=ハイハット。

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| 8ビート基本 | K `x... .... x... ....` S `.... x... .... x...` HH `x.x. x.x. x.x. x.x.` | ポップス、ロック全般 | Claude |
| 4つ打ち | K `x... x... x... x...` S `.... x... .... x...` HH `..x. ..x. ..x. ..x.` | ダンス、EDM | Claude |
| ハーフタイム | K `x... .... .... ....` S `.... .... x... ....` HH `x.x. x.x. x.x. x.x.` | バラード、ビルドの手前 | Claude |
| シンコペキック | K `x... ..x. ..x. ....` S `.... x... .... x...` HH `x.x. x.x. x.x. x.x.` | ノリが欲しいサビ | Claude |
| 16分HH | HH `xxxx xxxx xxxx xxxx` に8ビートのK・Sを重ねる | ボカロ、疾走系 | Claude |
| サイドスティック | スネアの代わりに、軽い音(リムショット)を使う | バラード、静かなAメロ | Claude |

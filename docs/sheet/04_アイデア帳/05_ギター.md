# ギター

矢印:↓がダウン、↑がアップ、`_` は休みです。

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| 定番8ビートストローク | ↓ ↓↑ _↑ ↓↑ | ポップス、フォーク | Claude |
| 8分ダウンのみ | ↓↓↓↓↓↓↓↓ | パンク、サビの勢い | Claude |
| アルペジオ | 低音弦から高音弦へ順に上り、戻る | バラード、Aメロ | Claude |
| カッティング | 16分で弾き、2拍・4拍にアクセント、間にミュート音を挟む | ファンク、シティポップ | Claude |
| パワーコード | ルートと5度だけを、8分で刻む | ロック、パンク | Claude |
| 単音リフ | ルート・5度・♭7などを使った短いフレーズ | イントロ、間奏 | Claude |
| クリーン+ディレイ | きれいな音に、1拍遅れのディレイを重ねる | バラード、アンビエント系 | Claude |

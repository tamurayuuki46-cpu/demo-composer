# 裏メロ

Demo Composerにあるもの:Sparse(隙間型) / Active(動く型) / Hook(フック型) / Answer(応答型)

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| 隙間を埋める | ボーカルが休む所に、短いフレーズを入れる | Aメロ、サビ | Claude |
| 応答 | ボーカルの語尾に、短く返す | サビ、間奏前 | Claude |
| 長い音のハーモニー | コードの3度や7度を、長く伸ばす | バラード、サビ | Claude |
| 下降ライン | サビの後半で、ゆっくり下がる旋律を重ねる | サビの終わり | Claude |
| 前のフレーズの反復 | 前のメロディの終わりを、そのまま繰り返す | 2番、ラスサビ | Claude |
| 3度・6度下を並行 | 主旋律の下で、3度か6度を保って並行して動く | サビ、ハモリと兼用 | Claude |

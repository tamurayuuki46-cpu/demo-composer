# 音ネタ(効果音・サンプル)

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| リバースシンバル | シンバルを逆再生して、次の頭に着地させる | サビの手前 | Claude |
| ライザー(ノイズスイープ) | ホワイトノイズを、フィルターで上げる | ビルドアップ | Claude |
| インパクト | 低い大きな音を、サビの頭に1回だけ | サビ頭、ドロップ | Claude |
| レコードノイズ | 針の音や、ノイズを薄く敷く | イントロ、ローファイ系 | Claude |
| 環境音 | 雨、駅、街の雑踏などを薄く重ねる | 場面を作る(テーマ・場面の欄と連動) | Claude |
| ボイスチョップ | 声を切り刻んで、リズムの素材にする | 間奏、ダンス系 | Claude |
| テープストップ | 再生が止まるように、音が下がって止まる | ブレイク、曲の切り替え | Claude |
| 小物パーカッション | シェイカー、タンバリンなどを、細かく重ねる | Aメロ、ノリの補強 | Claude |

# レイヤー(ハモリ)

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| 3度上のハモリ | 主旋律の3度上を、並行して歌う | サビ | Claude |
| 3度下のハモリ | 主旋律の3度下を、並行して歌う | サビ、落ち着いた場面 | Claude |
| 6度下のハモリ | 6度下を並行する | 厚みを出したい所 | Claude |
| オクターブ重ね | 同じ旋律を、1オクターブ上か下で重ねる | サビ、ラスサビ | Claude |
| 語尾だけハモる | フレーズの最後の音だけ、ハモリを足す | Aメロ、Bメロ | Claude |
| ユニゾンダブル | 同じ旋律を、少しだけずらして2回重ねる | 声の厚み、ボカロ | Claude |
| ロングトーンのコーラス | 「アー」「ウー」を、長く伸ばして重ねる | 間奏、サビの背景 | Claude |
| エコー(1拍遅れ) | 同じ言葉を、1拍遅れて返す | 余韻、夜のチル | Claude |
| | | | 自分 |
| | | | 自分 |
| | | | 自分 |

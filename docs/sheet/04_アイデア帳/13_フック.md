# フック

曲の中で一番覚えてほしい部分を、どう作るかの引き出しです。

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| 短いフレーズの3回反復 | 2〜4音の短い音形を、そのまま3回繰り返す | サビ頭 | Claude |
| 長い音から畳みかける | 1小節を伸ばしてから、次の小節で細かく言葉を入れる | サビ頭、Bメロの終わり | Claude |
| 印象的な跳躍 | サビの1音目で、6度かオクターブ上へ大きく跳ぶ | サビ頭 | Claude |
| リズムのフック | 同じ音を、シンコペーションで連打する | AメロやBメロ | Claude |
| タイトルの繰り返し | 曲名の言葉を、サビで何度も繰り返す | サビ | Claude |
| 掛け声・コール | 「ヘイ」「オー」などを、決まった位置で入れる | 間奏、ラストサビ | Claude |
| 楽器のフック | シンセやギターの短いフレーズを、曲中で何度も使う | イントロ、間奏 | Claude |
| 全員でキメる | 全パートが同じリズムで、短く揃えて鳴らす | サビ前、セクションの終わり | Claude |
| 無音のあとの1フレーズ | 全部止めて、ボーカルだけを1フレーズ入れる | ブレイク、ラストサビ前 | Claude |
| コードで外す | サビの途中で、♭VIなどの意外なコードを入れる | サビの後半 | Claude |
| | | | 自分 |
| | | | 自分 |
| | | | 自分 |

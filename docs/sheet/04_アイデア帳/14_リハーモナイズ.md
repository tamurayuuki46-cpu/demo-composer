# リハーモナイズ(ノンダイアトニックコード)

Cメジャーでの例です。メロディが変わらないか、新しいコードに合うかを、聴いて確かめます。

Demo Composerのコードは9種類(m7♭5・分数コードは未対応)なので、分数コードはベースの音で代用します。

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| サブドミナントマイナー | C G Am F を、C G Am Fm にする(IV を iv に) | サビ前、切なさを足したい所 | Claude |
| IVをiiに代える | C Am F G を、C Am Dm G にする | 落ち着かせたい所 | Claude |
| セカンダリードミナント | F G Em Am を、F G E7 Am にする(Em を E7 に) | 4536進行の変化 | Claude |
| ツーファイブ化 | C Am G を、C Am Dm7 G7 にする | 解決を強めたい所 | Claude |
| トライトーン代理 | Dm7 G7 C を、Dm7 D♭7 C にする | 洒落た終止 | Claude |
| パッシングディミニッシュ | C C#dim7 Dm7 G7 のように、半音で上がる所に挟む | 半音でつなぎたい所 | Claude |
| プラガル終止 | C F Fm C(IV のあとに iv を置く) | 曲の終わり、切ない余韻 | Claude |
| ♭VI ♭VII I | A♭ B♭ C(借用和音で、強く終わる) | サビの終わり、ラスサビ | Claude |
| ベースの下行 | C G/B Am Am/G F(ベースだけが C B A G F と下がる) | サビ、バラード | Claude |
| ラインクリシェ | Am Am(maj7) Am7 Am6(1音だけ半音ずつ動く) | イントロ、Aメロ | Claude |
| ナポリの和音 | C F D♭ G C(D♭ を V の前に置く) | 哀愁を出したい所 | Claude |
| | | | 自分 |
| | | | 自分 |
| | | | 自分 |

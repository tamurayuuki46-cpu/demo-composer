# 定番の転調

Cメジャーを元のKeyにした例です。Demo ComposerのKey変更は曲全体の移調なので、曲の途中の転調は、コードを手で並べて作ります。

| 名前 | 中身 | 向く場所 | 出どころ |
|---|---|---|---|
| 半音上げ(直接) | 元のKeyの最後を G で止め、そのまま D♭ で次のサビに入る(C → D♭) | ラスサビ | Claude |
| 半音上げ(ツーファイブ経由) | E♭m7 → A♭7 → D♭ と、新しいKeyの ii-V を通って入る | ラスサビ、なめらかに入りたい所 | Claude |
| 全音上げ | Em7 → A7 → D と、新しいKeyの ii-V を通って入る(C → D) | ラスサビ、自然に盛り上げたい所 | Claude |
| 短3度上げ | B♭7 → E♭ と、新しいKeyの V7 から入る(C → E♭) | ラスサビ、大きく変えたい所 | Claude |
| 属調へ(C → G) | Am7 → D7 → G。Am7 は、元のKeyの vi と、新しいKeyの ii を兼ねる(ピボットコード) | Bメロ、サビ | Claude |
| 下属調へ(C → F) | C → C7 → F。C を C7 に変えて、F の V7 にする | Bメロ、サビ | Claude |
| 平行調へ(C → Am) | Dm → E7 → Am と、新しいKeyの V7 を通って入る。使う音は同じ | Aメロからサビ、雰囲気を変えたい所 | Claude |
| 同主調へ(C → Cm) | C のあとに G → Cm と入るか、直接 Cm にする。ルートは同じで、明るさだけが暗く変わる | 間奏、Cメロ | Claude |
| 部分転調 | Bメロの途中だけ別のKey(例:Am)へ行き、サビで元の C に戻る | Bメロ、Cメロ | Claude |
| 落ちサビ → 半音上げ | 落ちサビ(静かな部分)から、ブレイクを入れ、半音上げでラスサビに入る | ラスサビ前 | Claude |
| 転調を予告する | 転調の1小節前に、ドラムをブレイクかビルドにして、聴き手に準備させる | ラスサビ前 | Claude |
| メロディを持ち上げる | 転調前のサビのメロディを、そのまま新しいKeyに移して、もう一度歌う | ラスサビ | Claude |
| | | | 自分 |
| | | | 自分 |
| | | | 自分 |

## 転調のあとに確認すること

- [ ] 転調後の最高音が、歌える高さに収まっている
- [ ] 新しいKeyのまま終わるか、元に戻すかを決めた
- [ ] 転調の前後で、同じメロディとコードのまま、Keyだけが変わっているか聴いた
- [ ] 転調は1曲に1回までに絞った(使いすぎない)
- [ ] ラスサビの音量やアレンジも、転調と合わせて盛り上げた

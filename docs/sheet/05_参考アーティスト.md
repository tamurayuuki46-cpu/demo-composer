# 参考アーティスト

作曲で「この人の、ここを借りたい」を記録する表です。曲のコピーではなく、残します。メロごとの参考欄(1枚目のタブ)に書く前の、候補置き場として使います。

## 借りたい点の分け方

- **旋律**:音の動き、跳躍、音域、フレーズの長さ
- **コード**:進行、借用和音、テンションの使い方
- **リズム**:ノリ、シンコペーション、テンポ感
- **音色**:シンセ、ギター、ボーカルの質感
- **構成**:サビの入り方、間奏の置き方、山谷
- **歌詞・言葉**:言葉の選び方、語尾、情景

### サウンドエフェクト(作中の効果音)

作中の効果音は、曲の中の「音ネタ」(アイデア帳の「音ネタ」の引き出し)として使えます。曲名ではなく、**音の種類**で探します。

| 種類 | 聴きどころ | 曲の中での使い方 |
|---|---|---|
| 場面転換の音(ウィップ・スイープ) | 一瞬で場面が変わる、風を切るような音 | セクションの切り替え |
| 衝撃音(インパクト・ヒット) | 低く大きい一発の音。映画の予告編でよく聴く | サビ頭、ドロップ |
| ライザー | だんだん高く、大きくなる音 | サビ前のビルドアップ |
| ゲームの取得音・決定音 | 短く明るい、報酬を感じる音(コイン、レベルアップなど) | 軽いアクセント、イントロ |
| アニメの決めの効果音 | 「キラリ」「ガーン」のような、感情を強調する音 | フレーズの終わりの飾り |
| 環境音 | 雨、風、駅、街の雑踏 | 場面を作る(テーマ・場面の欄と連動) |
| ドラマ・映画の場面転換音 | 短いジングル、アイキャッチの音 | 間奏、曲の区切り |

### 使い方

1. 作っているパートを決め、その担当の表から、聴く
2. 「学べること」を、アイデア帳の該当パートの空欄に、1行書き写す
3. 弾けなくても大丈夫です。耳で聴いて、リズムや音の置き方だけを真似する

この表も、私の知識から作りました。曲名や「学べること」は、聴いて確かめてください。松本孝弘と上原ひろみは、曲名を特定できなかったので、アルバム単位で聴くことを勧めています。

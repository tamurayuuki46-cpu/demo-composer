# ジャンルリスト

作る曲のジャンルを選ぶときの、大雑把な手がかりです。BPMやコードは目安であり、曲によって変わります。ジャンルの境界は曖昧なので、**近い曲を聴いて確かめる**のが確実です。

## 選ぶときのチェック

- [ ] ジャンルを選んだ理由を一言で言える(「この曲の場面に合う」など)
- [ ] 同じジャンルの参考曲を、1〜2曲聴き、BPMとリズムを確かめた
- [ ] 2つのジャンルを混ぜるなら、主と副を決めた
- [ ] テンポがジャンルの目安と大きくずれている場合、理由がある

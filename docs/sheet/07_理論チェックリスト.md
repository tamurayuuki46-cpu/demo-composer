# 理論チェックリスト

作曲用語を使って、自分の曲を点検するための表です。全部に✓を付ける必要はありません。引っかかった項目だけ見直します。

## 1. 曲全体

- [ ] **Key / Scale**:使う音階(Major / Minor)を決めた。サビの高音がKeyに合っているか
- [ ] **BPM**:速さが曲の心情に合っている(ゆっくり=しっとり、速い=疾走感)
- [ ] **構成**:Aメロ・Bメロ・サビの並びが決まっている。サビまでが長すぎない
- [ ] **山谷(ダイナミクス)**:サビが一番高く、手前のBメロで助走がある

## 2. コード進行

- [ ] **ダイアトニックコード**:基本は、Keyの7つのコード内で組めている
- [ ] **機能(T・SD・D)**:安定(トニック)→ 動き(サブドミナント)→ 緊張(ドミナント)の流れがある
- [ ] **終止**:フレーズの終わりが、落ち着く(解決)か、あえて浮かせる(半終止)か意識している
- [ ] **借用和音**:同主調から1つだけ借りて、色を変える場所を決めた(例:サビ前のサブドミナントマイナー)
- [ ] **セカンダリードミナント**:次のコードへ強く向かわせたい所に、1回だけ使った
- [ ] **転調**:使うなら、Cメロやラストサビ前など、1か所に絞った
- [ ] **テンション(9th・11th・13th)**:足しすぎず、響きを足したい所だけにした
- [ ] **ループ感**:4小節か8小節で戻る進行で、飽きないよう小節ごとに変化がある

## 3. メロディ

- [ ] **コードトーン**:長い音、拍の頭は、コードの構成音に置けている
- [ ] **経過音・刺繍音**:短い音は、前後の音をつなぐ飾りとして使えている
- [ ] **倚音・逸音**:緊張させたい音は、狙って使い、ちゃんと解決している
- [ ] **音域**:歌える範囲に収まり、サビの最高音が一度だけ頂点になる
- [ ] **跳躍**:大きく跳んだ後は、逆方向へ戻している
- [ ] **モチーフ**:短いフレーズ(2〜4音)を繰り返し、変えて使った
- [ ] **シーケンス**:同じ形を、音の高さをずらして繰り返した所がある
- [ ] **同音連打**:続きすぎていない。リズムか音の変化がある
- [ ] **Hook(フック)**:一番覚えてほしい1フレーズを決めた

## 3-2. メロディの周辺用語

### リックと近い言葉

- [ ] **モチーフ**:曲の元になる最小の音形(2〜4音)。これを変えて繰り返すと曲に統一感が出る
- [ ] **フレーズ**:息継ぎまでの1まとまり(1〜2小節)。Aメロは短く、サビは長く、で変化をつけた
- [ ] **リック**:短い決まり文句のような音形(ブルース・ギター由来)。フレーズの合間に挟むと「らしさ」が出る
- [ ] **リフ**:繰り返す短いフレーズで、曲の骨格になるもの。伴奏やベースにも使う
- [ ] **シーケンス**:同じ形を高さをずらして繰り返す。盛り上がりの手前で使った
- [ ] **オスティナート**:同じ音形をずっと繰り返す。背景に置くと、緊張を保てる
- [ ] **コール&レスポンス**:呼びかける旋律に、別のパートが答える(裏メロの「応答」と同じ考え方)

### ガイドトーンと2度・6度

- [ ] **ガイドトーン(3度・7度)**:コードの性格(長調か短調か、7thがあるか)を決める音。サビの長い音に使うと、コードの色が明確になる
- [ ] **3度の動き**:コードが変わるとき、前のコードの3度や7度から、次のコードの3度や7度へ、半音か全音で動いている
- [ ] **2度(9thにあたる音)**:コードのルートの隣の音。浮遊感が出る。拍の頭に置くと、ぶつかりやすいので長さに注意
- [ ] **6度(13thにあたる音)**:明るく、やわらかい響き。語尾や、サビの高い音に置くと開放感が出る
- [ ] **使い分け**:安定させたい所は3度・5度、浮かせたい所は2度・6度、と決めた

### 非和声音の働き

- [ ] **経過音**:コードトーンの間を、順に動いてつなぐ音
- [ ] **刺繍音**:同じ音の上か下へ行って戻る飾りの音
- [ ] **倚音**:拍の頭でわざと外し、次の音で解決させる音
- [ ] **先取音**:次のコードの音を、少し早く鳴らす音(疾走感が出る)

### ターゲットとアプローチ

- [ ] **ターゲットノート**:小節の頭やコードが変わる所で着地させたい音を決めた(コードトーン、特に3度・7度が安定する)
- [ ] **アプローチノート**:ターゲットの直前に置く、そこへ導く音。ターゲットに着く手前で、次の動きを予告できている
- [ ] **クロマチックアプローチ**:ターゲットの半音上か半音下から入る。スケール外でも、短ければ自然に聞こえる
- [ ] **ダイアトニックアプローチ**:ターゲットの隣の音(スケール内)から入る。素直で歌いやすい
- [ ] **エンクロージャー**:ターゲットを上と下から挟んでから着地する(上→下→ターゲット)。ジャズやフュージョンっぽい動き
- [ ] **ダブルクロマチック**:半音を2つ続けて、ターゲットへ入る。勢いがつく
- [ ] **傾向音と解決**:導音(7度)は主音へ、4度は3度へ、のように、引っ張る音の行き先を決めた

### コード外の音と持続

- [ ] **ノンコードトーン(コード外音)**:コードの構成音以外の音の総称。短く使い、長い音には置かない
- [ ] **アボイドノート**:コードトーンの半音上にある音(例:Cのコードに対するF)。長く伸ばすと濁るので、避けるか短くした
- [ ] **係留音**:前のコードの音を次のコードへ持ち越し、遅れて解決させる。切なさや引っかかりが出る
- [ ] **保続音(ペダルトーン)**:コードが変わっても、同じ音(多くは低音)を鳴らし続ける。緊張を保てる
- [ ] **ブルーノート**:♭3・♭5・♭7を、短く、あえて使う。ロックやブルース系の味が出る
- [ ] **スケール外の音**:使うときは、短い音か、すぐ解決する場所だけにした

### メロディのコードからの度数

メロディの音が、そのときのコードの何度にあたるかを見ます。Demo Composerのメロディ分析の「Chordからの度数」でも確認できます。

- [ ] **小節の頭・長い音の度数**:その音が、コードのルート・3度・5度・7度(コードトーン)になっている
- [ ] **3度・7度**:コードの性格を決める音を、サビの大事な所に置いた
- [ ] **2度(9th)・6度(13th)**:浮遊感や、やわらかさを出したい所に使った
- [ ] **4度(11th)**:長く伸ばすと濁りやすい。使うなら、短い音か、経過の音にした
- [ ] **半音のぶつかり**:コードトーンの半音上の音を、長く鳴らしていない
- [ ] **度数の偏り**:全部がコードトーンだと安定しすぎ、外れが多いと不安定になる。どちらに寄せたいか決めた
- [ ] **コードが変わる所**:変わった瞬間に、メロディの音が新しいコードの何度か確認した

### アボイドノート(避ける音)

コードトーンの半音上にあたり、長く伸ばすと濁って聞こえやすい音です。基本の目安として、次の音を確認します。

- [ ] **メジャー系のコード**(C・Cmaj7など):4度(Cに対するF)を、長く伸ばしていない
- [ ] **ドミナント7th**(G7など):4度(G7に対するC)を、長く伸ばしていない
- [ ] **マイナー7th**(Dm7など):♭6度(Dm7に対するB♭)を、長く伸ばしていない
- [ ] **短い音や経過音なら大丈夫**:避ける音を使うときは、短くして、次の音で解決させた
- [ ] **聴いて確かめた**:理論上は避ける音でも、あえて使うと味になる場合があるので、鳴らして判断した

## 4. ベース

- [ ] **ルート音**:コードの根音で支える所を基本にしている
- [ ] **キックとの関係**:ベースとキックの位置が、ぶつからずに重なる
- [ ] **経過・アプローチ**:コードが変わる直前に、次の音へ向かう動きがある
- [ ] **休符**:サビ前は音数を減らすなど、休む所を決めた

## 5. リズム・ドラム

- [ ] **グルーヴ**:ハネ(スウィング)か、ストレートか決めた
- [ ] **シンコペーション**:拍の裏に置く音で、ノリを作る所がある
- [ ] **フィル**:セクションの終わりに入れて、次の山へつなげている
- [ ] **抜き(ブレイク)**:落とす所を作って、直後のサビを立たせている

## 6. 裏メロ(カウンターメロディ)

- [ ] **隙間**:主旋律が休む所に入れている
- [ ] **役割**:応答(返す)・持続(支える)・動き(絡む)のどれにするか決めた
- [ ] **ぶつかり**:主旋律と同じ音域・同じ拍で重ならない

## 7. リフ・上もの・レイヤー

- [ ] **リフ**:曲の顔になる短い繰り返しがある(ギター、シンセ、ベースのどれか)
- [ ] **上もの**:コードとメロ以外の、上に乗るパート(シンセ、ストリングス、ピアノの飾りなど)の役割を決めた
- [ ] **レイヤー**:同じパートに音色を重ねる。サビだけ重ねて、厚みの変化を作った
- [ ] **音域の分担**:低音・中音・高音を、別のパートが担当している(同じ帯域で重ならない)

## 8. ハモリと対位法

- [ ] **ハモリ**:主旋律の上か下に、並行して動く旋律を付けた(3度や6度が基本)
- [ ] **オクターブ重ね**:同じ旋律を1オクターブ上か下で重ねて、厚くした
- [ ] **対位法**:2つ以上の独立した旋律が、同時に流れている(主旋律と裏メロの関係)
- [ ] **反行**:一方が上がる時に、もう一方が下がる。ぶつからずに独立して聞こえる
- [ ] **平行5度・8度**:2つのパートが同じ幅で動き続けていない(独立性が薄れるため)
- [ ] **ハモリの終わり**:最後は、主旋律の音とそろえて終わるか、あえてずらすかを決めた

## 9. スケール(ペンタ・エスニック)

- [ ] **マイナーペンタ**:1・♭3・4・5・♭7の5音。外れにくく、ロックやブルース系に合う
- [ ] **メジャーペンタ**:1・2・3・5・6の5音。4度と7度がなく、明るく安心感がある
- [ ] **ハーモニックマイナー**:1・2・♭3・4・5・♭6・7。7度が半音上がり、強い解決感と、少しエキゾチックな響きが出る
- [ ] **メロディックマイナー**:上行は1・2・♭3・4・5・6・7(6度と7度を半音上げる)。ハーモニックマイナーの不自然な隙間がなくなり、上がる旋律がなめらかになる。クラシックでは下行時にナチュラルマイナーへ戻す。ジャズでは上行形のまま使う
- [ ] **都節(みやこぶし)音階**:1・♭2・4・5・♭6。日本的な、哀愁のある響き
- [ ] **律音階**:1・2・4・5・6。都節より明るく、雅楽や民謡に近い
- [ ] **琉球音階**:1・3・4・5・7。2度と6度がなく、沖縄らしい響き
- [ ] **フリジアン・ドミナント**:1・♭2・3・4・5・♭6・♭7。スペイン風、中東風の響き
- [ ] **ハンガリアンマイナー**:1・2・♭3・#4・5・♭6・7。ハーモニックマイナーに#4を足した、暗くて妖しい響き
- [ ] **ダブルハーモニック(アラビア風)**:1・♭2・3・4・5・♭6・7。♭2と♭6が強く、アラブ、インド系の響きになる
- [ ] **ヨナ抜き(長音階)**:ドレミソラ(1・2・3・5・6)。4度と7度がなく、日本の歌謡曲や童謡の懐かしさが出る
- [ ] **ヨナ抜き(短音階)**:ラドレミソ(1・♭3・4・5・♭7)。演歌や民謡の哀愁が出る(マイナーペンタと同じ音)
- [ ] **中国音階(五声)**:宮・商・角・徴・羽(1・2・3・5・6)。メジャーペンタと同じ音で、旋律の動かし方で中華風になる
- [ ] **使う範囲**:エスニックな音階は、一部の旋律だけに使うか、曲全体に使うかを決めた(混ぜすぎない)

## 10. リハーモナイズ

- [ ] **リハーモナイズ**:同じメロディに、別のコードを付け直して、雰囲気を変えてみた
- [ ] **代理コード**:機能が近いコードに置き換えた(例:IV の代わりに ii、V の代わりに iii など)
- [ ] **メロディとの相性**:メロの長い音が、新しいコードの構成音か、きれいなテンションになっている
- [ ] **元に戻せる**:変更前の進行も残して、聴き比べた
- [ ] **やりすぎ**:1か所ずつ試し、コードの変化が、メロの印象を消していない

### リハーモナイズの方法(Cメジャーでの例)

- [ ] **トニック代理**:I(C)の代わりに vi(Am)か iii(Em)を使い、安定感をやわらげた
- [ ] **サブドミナント代理**:IV(F)の代わりに ii(Dm)を使い、軽く動かした
- [ ] **ドミナント代理**:V7(G7)の代わりに vii°(Bm7♭5)を使い、緊張感を変えた
- [ ] **トライトーン代理**:V7(G7)を ♭II7(D♭7)に置き換え、ベースが半音で下がって着地する形にした
- [ ] **ツーファイブ化**:V7の前に、そのコードの ii(Dm7)を足した(Dm7 → G7)
- [ ] **セカンダリードミナントの追加**:目的のコードの前に、その V7 を置いた(例:Am の前に E7)
- [ ] **パッシングディミニッシュ**:半音上がるコードの間に、dim7を挟んだ(C → C#dim7 → Dm)
- [ ] **オンコード(分数コード)**:ベースだけを動かして、なめらかにつないだ(C → G/B → Am)
- [ ] **ラインクリシェ**:同じコードのまま、1音だけを半音ずつ動かして変化を出した
- [ ] **メロディの長い音を確認**:新しいコードの構成音か、きれいなテンション(9th・13th)になっている
- [ ] **変えすぎない**:サビの頭と終わりのコードは、元のまま残して聴き比べた

## 11. ノンダイアトニックコード

Keyの7つのコード(ダイアトニック)以外を、ノンダイアトニックコードと呼びます。使うと響きの色が変わります。1曲に1〜2か所に絞るのが目安です。

### 借用和音(同主調からの借用)

- [ ] **サブドミナントマイナー iv(Fm)**:IVの代わりに入れる。切なさが一気に増す。サビ前の定番
- [ ] **♭VI(A♭)**:短調の響きを借りた、広がりのある和音。盛り上がりや、切ない流れに使う
- [ ] **♭VII(B♭)**:ロックやポップスの定番。I に戻ると、開放感が出る
- [ ] **♭III(E♭)**:明るい中に影を足す。♭VI・♭VIIと組み合わせる
- [ ] **♭VI → ♭VII → I**:ロックや疾走系でよく使う、強い終わり方

### ドミナントの仲間

- [ ] **セカンダリードミナント**:V7/ii = A7、V7/iii = B7、V7/IV = C7、V7/V = D7、V7/vi = E7(それぞれ次のコードへ向かう)
- [ ] **解決先を決めた**:セカンダリードミナントを置いた場所で、次のコードが、予想どおりのコードになっている
- [ ] **ナポリ(♭II)**:D♭。V へ向かう直前に置く、独特の哀愁。1か所だけにする

### 経過・特殊

- [ ] **ディミニッシュ(dim7)**:半音でつなぐ経過の和音。短く使い、次の和音へ必ず進める
- [ ] **オーグメント(aug)**:浮遊感や、不安定さ。長く伸ばさない
- [ ] **短調のメジャー V**:短調でも、V だけをメジャーにして、強い終止にした
- [ ] **ドリアンの IV**:短調の中に、メジャーの IV を置き、明るさを足した

### 使い方の確認

- [ ] **1曲に1〜2か所**:使いすぎず、使う場所(サビ前、Bメロの終わりなど)を決めた
- [ ] **ベースの動き**:ノンダイアトニックコードのルートが、半音や順次進行でつながっている
- [ ] **メロディとの衝突**:メロディの長い音が、新しいコードと半音でぶつかっていない(アボイドノート)
- [ ] **元の進行と聴き比べた**:入れる前と、入れた後を、続けて聴いた

### Demo Composerで試すとき

- [ ] **ひとスパイス**:Chord画面の「ひとスパイス」(借用和音の3候補)で、借用和音を試せる
- [ ] **使えるコードの種類**:Major・Minor・7・Maj7・m7・sus2・sus4・dim・augの9種類。m7♭5・分数コード・テンションつきは未対応なので、ベースと音で近い形を作る
- [ ] **Keyをまとめて移調**:試したあと、Hubの Key変更で、全体をまとめて移調できる

## 12. 転調

Cメジャーでの例です。1曲に1回くらいを目安にします。

- [ ] **半音上げ(C → D♭)**:ラスサビ前の定番。気分が一気に上がる
- [ ] **全音上げ(C → D)**:半音上げより、自然に盛り上がる
- [ ] **直接転調**:つなぎなしで、いきなり新しいKeyに入る。強い印象になる
- [ ] **ドミナント経由の転調**:新しいKeyの V7(D へなら A7)を置いてから入る。自然につながる
- [ ] **ピボットコード**:両方のKeyに属するコードを経由して、なめらかに入る
- [ ] **平行調への転調(C → Am)**:使う音は同じで、雰囲気だけが変わる
- [ ] **同主調への転調(C → Cm)**:ルートは同じで、明るさから暗さへ変わる
- [ ] **部分転調**:Bメロなど、一部だけで転調して、元のKeyに戻る
- [ ] **転調前の準備**:転調の直前に、緊張(V7、ブレイク、休符)を作った
- [ ] **音域**:転調したあとの最高音が、歌える高さに収まっている
- [ ] **終わり方**:転調したあとは戻らず、新しいKeyで終わるか、戻るかを決めた
- [ ] **聴いて自然か**:転調したあとのメロディが、新しいKeyで違和感なく歌える

Demo ComposerのKey変更は、曲全体を移調する機能です。曲の途中の転調は、コードを手で並べて作ります。メロディ分析のKeyからの度数は、曲全体のKeyを基準にするため、転調したあとの部分は「Scale外」に見えることがあります。

## 13. 静と動の対比

- [ ] **静と動の割合**:静かな時間と、盛り上がる時間を、意識して配分した
- [ ] **音数の差**:静は音を少なく、動は音を増やした
- [ ] **音域の差**:静は低め・狭め、動は高め・広めにした
- [ ] **ドラムの差**:静はハットだけにするか抜き、動はフルで入れた
- [ ] **音量の差**:静と動で、音量(ダイナミクス)を変えた
- [ ] **引き算**:静を作るために、Aメロなどで音を減らした
- [ ] **ブレイク**:サビの前に、一瞬の無音か、音を抜く場所を作った
- [ ] **溜めて解放**:静から動へ入る前に、ビルド(ライザー、スネアロール)で期待を作った
- [ ] **動の続けすぎ**:盛り上がりが続いて、疲れる所がない。間奏やCメロで一度静にした
- [ ] **落ちサビ**:ラストのサビ前に、静かな部分を入れて、最後の動を強めた
- [ ] **静でも飽きさせない**:静の部分に、小さな変化(音色の足し引き、裏メロ)を入れた
- [ ] **感情の山と一致**:音の盛り上がりが、1枚目の山谷の表と合っている

## 14. 最後の見直し

# 構成ストック

曲ごとの骨子(構成)パターンを、ここに貯めます。作り終えた曲や、参考曲の構成を聴いて記録し、次の曲で「型」として使い回します。

## 書き方

- 並べ方:`Intro4 / A8 / B8 / サビ8 ...` のように、**セクション名+小節数**をスラッシュでつなぐ
- 山谷:各セクションの盛り上がりを「低・中・高」で書く(例:A低 → B中 → サビ高)
- Demo Composerの制限:24セクション・合計128小節まで
- 「叩き台」の行は、こちらで用意した候補です。実際の曲の構成を写したものではありません

## 貯めるときのチェック

- [ ] サビがどこで初めて出てくるか(何小節目・何秒目か)を記録した
- [ ] 山谷を「低・中・高」で書いた
- [ ] 間奏やCメロが、どこで空気を変えているかを一言メモした
- [ ] 「向いている曲」を書き、次に選ぶときの手がかりにした
- [ ] 使った型は、Demo ComposerのArrangeの構成テンプレートで再現してみた

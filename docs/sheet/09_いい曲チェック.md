# いい曲チェック

曲を作ったあとに、「弱い所」を見つけるためのチェックリストです。これを満たせば必ずいい曲になるというものではありません。**直す順番を決めるための道具**です。理論チェックリストが「用語で点検する」もので、こちらは**聴いて、聴き手の目で確かめる**ものです。

## 進め方

1. まず1回、手を止めずに通して聴く
2. 上から順に、ひっかかった項目だけに✓を外す
3. 最後の点数表で、一番低い項目をひとつだけ直す

## 1. 最初の30秒

- [ ] 出だしで、曲の世界(場面・心情)が伝わる
- [ ] イントロが長すぎず、ボーカルが入るまでに飽きない
- [ ] Aメロが、サビより明らかに控えめで、続きが聞きたくなる
- [ ] サビまでの時間が長すぎない(目安:1分前後まで)

## 2. サビ

- [ ] 1回聴いて、口ずさめる部分がある
- [ ] 曲の中で、サビが一番盛り上がっている
- [ ] サビの頭に、印象に残る一音か・一拍がある(フック)
- [ ] サビの最高音が、歌える高さに収まっている
- [ ] Bメロからサビへ入るときに、「来た」という感じがする
- [ ] サビのコードとメロディが、きれいに合っている

## 3. メロディ

- [ ] 歌える音域に収まっている(極端に高い・低い音が続かない)
- [ ] 息をする場所がある(フレーズが長すぎない)
- [ ] 歌詞を乗せたときに、言葉のアクセントとリズムが合う
- [ ] 同じ形(モチーフ)が繰り返され、変化もある(同じだけでも、ばらばらでもない)
- [ ] 同じ音の連打や、同じリズムが続きすぎていない
- [ ] 長い音が、コードの構成音か、きれいなテンションになっている
- [ ] フレーズの最後の音が、言い切るか、あえて浮かせるかが決まっている

## 4. コード・和声

- [ ] 進行に流れがあり、単調にならない
- [ ] 変化をつける場所が、1〜2か所に絞られている
- [ ] メロディの長い音が、コードとぶつかって濁っていない
- [ ] サビ前に緊張があり、サビで解決するように感じる
- [ ] 同じ進行の繰り返しで、飽きる所がない

## 5. 展開・構成

- [ ] 山谷(盛り上がり)が、聴いてわかる
- [ ] 2回目のセクションで、何か変化がある(アレンジ・裏メロ・音色)
- [ ] 間奏やCメロが、空気を変えている
- [ ] 曲の長さが、内容に対して長すぎない・短すぎない
- [ ] 終わり方(アウトロ)が、曲の余韻と合っている

## 6. リズム・グルーヴ

- [ ] ノリが曲を通して一貫している(テンポとリズムが合う)
- [ ] セクションごとに、ドラムの密度が変わる
- [ ] ベースとキックが、ぶつからずにはまっている
- [ ] フィル・ブレイクが、つなぎ目で効いている

## 7. アレンジ・音色

- [ ] 主役(メロディやボーカル)が、1つにはっきりしている
- [ ] 伴奏や裏メロが、主役を邪魔していない
- [ ] 音数が多すぎない(引くところを試した)
- [ ] 音色の方向が、テーマ・心情と合っている
- [ ] 低音・中音・高音の分担が、バランスよく見える

## 8. 独自性

- [ ] 参考曲と、メロディの並びが似すぎていない
- [ ] コード進行が同じでも、メロディやリズムに自分らしい点がある
- [ ] 「今回挑戦する技法」(1メロで決めたもの)を、実際に使えた
- [ ] この曲だけの、一つの特徴が言える

## 9. テーマ・心情との一致

- [ ] 1枚目のシートの「場面」「心情」が、音に出ている
- [ ] 曲を一言で説明できる
- [ ] 山谷が、テーマの感情の動きと合っている

## 10. 聴き手の目で確かめる

- [ ] 一晩おいて、翌日に聴き直した
- [ ] スマホのスピーカーでも、イヤホンでも、同じように良いと感じる
- [ ] 作った本人ではない人に、聴かせて、感想を3つの言葉で聞いた
- [ ] 飽きたところ・聴き流したところに、印を付けた

## 11. 浮遊感

浮遊感は、狙った場面(夜・夢・余韻など)にだけ使うと効きます。ずっと続けると、曲の輪郭がぼやけます。

- [ ] 狙った場面で、地に足がつかない感じが、聴いてわかる
- [ ] 長い音に、2度(9th)や6度(13th)を使って浮かせている
- [ ] コードの働きを弱めている(sus4、add9、maj7、同じコードの繰り返しなど)
- [ ] ベースがルートから離れる(オンコード)か、同じ音を保つ(保続音)ので、根が見えにくい
- [ ] 拍の頭を避けている(休符から入る、シンコペーション、小節をまたぐ長い音)
- [ ] パッド・リバーブ・ディレイで、空間の広がりを作っている
- [ ] ドラムを薄くしている(ハーフタイム、キックを減らす、ハットだけ)
- [ ] 音数が少なく、テンポも、ゆったり感じる
- [ ] 音色の方向が、Airy や Dreamy の方に寄っている
- [ ] 浮かせたままにせず、どこか(サビ頭など)で着地させる場所がある

## 12. 緊張と解決

- [ ] 緊張の原因が決まっている(V7、sus、テンション、半音のぶつかり、高い音域、音数やドラムの密度など)
- [ ] 解決する場所が決まっている(サビ頭、フレーズの終わりのトニックなど)
- [ ] 緊張が積み上がってから解決している(Bメロからサビへのビルドなど)
- [ ] 解決の強さを選んでいる:完全終止(V→I)は強く落ち着く、半終止(→V)は宙に浮く、偽終止(V→vi)は意外な方向へ逸れる
- [ ] 解決をわざと遅らせる場所がある(偽終止、sus4のあとに解決など)
- [ ] メロディの傾向音を、解決させている(導音7度は主音へ、4度は3度へ)
- [ ] リズムや音量の緊張と解決がある(ブレイクで止めて、サビで一気に開くなど)
- [ ] 緊張が長すぎて、解決しないまま疲れる所がない
- [ ] 解決ばかりで、平坦になっていない
- [ ] 解決したあとに、次の小さな緊張があり、曲が先へ流れていく
- [ ] 浮遊感(11)と使い分けている:浮遊感は解決を遠ざける、緊張と解決は先へ進める

## 直す順番

上流(曲の骨格)から直します。メロディが弱いままで、ミックスで直すことはできません。

1. **サビ**(フック・盛り上がり・メロディ)
2. **メロディとコード**(歌いやすさ・ぶつかり)
3. **構成・山谷**(飽き・長さ)
4. **アレンジ**(主役と伴奏の分担)
5. **音色・ミックス**(最後に、バランスを整える)

## やめどき

- [ ] 直す項目を「一番低いもの1つ」に絞って、3回までで次へ進む
- [ ] 「もうこれ以上、良くならない」と感じたら、一旦公開用に書き出した
- [ ] 公開後の反応を、次の曲のメモに残した

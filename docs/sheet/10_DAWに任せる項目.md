# DAWに任せる項目

Demo Composerでは「何を・どの方向で」作るかを決め、Cubasis / CubaseなどのDAWで「細部の音作りと仕上げ」をします。このタブは、DAW側に回す項目を分類して、**事前に決めておく方向**を一緒に書いたものです。

## 境目の考え方

- **Demo Composerで決める**:コード進行、メロディ、ベース、リズム、構成、裏メロ、音色の方向性(タグ)
- **DAWで作る**:音色の詳細、演奏の細かい表情、歌の調整、ミックス、マスタリング
- 迷ったら、「これは音を鳴らす前に、言葉で決められるか」を見る。決められるならDemo Composer、聴いて調整するならDAWです

## 1. 歌・ボーカロイドの表現

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| しゃくり | 音の頭を少し下からしゃくり上げて入るピッチの動き | どこで使うか(サビ頭など)、多いか少ないか |
| フォール・ポルタメント | 語尾を下げる、音と音を滑らかにつなぐ | 語尾を柔らかくするか、切るか |
| ビブラート・こぶし | 長い音の揺らぎ、装飾の量 | 装飾の量を控えめにするか、豊かにするか |
| ブレス・息づかい | 息を吸う音、息混じりの質感 | 親密な質感か、クリアな質感か |
| 発音・子音のタイミング | 歌詞の子音を拍より少し前にする、語尾を整える | 歌詞の読みやすさを重視するか |
| ボカロソフトの調整 | ピッチ曲線、ダイナミクス、声質パラメータ、語尾を1つずつ調整 | どのボーカル(VOCALOID、Synthesizer V、重音テトなど)を使うか |
| ハモリ・コーラス | パートを足して、ぶつからないよう音の高さを変える | どこに、何度のハモリを付けるか |
| ボーカルミックス | ピッチ補正、ディエッサー、コンプ、空間系エフェクト | ボーカルを前に出すか、トラックと馴染ませるか |

## 2. ヒューマナイズ(人間らしさ)

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| ベロシティの揺らぎ | 音の強弱を、一定にせずばらつかせる | 拍の強弱を、どこに置くか |
| タイミングのずれ | 拍から、ごくわずかにずらす | グリッドにきっちり合わせるか、揺らすか |
| もたらせる(後ノリ・レイドバック) | どのパートを、後ろにずらしてもたつかせるか | ノリを緩めたいパート(スネア、ギターなど) |
| 突っ込む(前ノリ) | 拍より少し前に置き、勢いを出す | 疾走感が欲しいパート |
| スウィング量 | 8分・16分を、どれくらい跳ねさせるか | ストレートか、ハネるか |
| 音の長さ(レガート・スタッカート) | 音をつなげるか、短く切るか | フレーズごとのなめらかさ |
| ゴーストノート | 聴こえるかどうかの弱い音を少し入れる | ドラムやベースのノリを細かくするか |

## 3. 楽器の詳細テクニック

### ギター

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| ストロークとアルペジオ | コードの鳴らし方と、ダウン・アップの強弱 | かき鳴らすか、一音ずつ弾くか |
| ミュート・カッティング | 音を止めて、リズムを刻む | ファンク寄りにするか |
| スライド・ハンマリング・プリング | 音を滑らかにつなぐテクニック | リックやフレーズをどこに入れるか |
| チョーキング・ビブラート | 長い音の変化 | ロックのソロやリックで使うか |
| ダブリング | 同じパートを重ねて厚くする | 左右に振るか |

### ピアノ

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| 左手と右手の役割 | 低音を左、和音・メロを右で分ける | 低音にオクターブを使うか |
| ペダル | 音の残響と、濁りの調整 | しっとりか、軽いか |
| アルペジオ・分散和音 | 和音の分散と、音の流れ | Demo ComposerのBacking Patternを参考にする |
| ベロシティの階段 | メロディを浮かせ、伴奏を弱くする | メロと伴奏のバランス |

### ベース

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| 音の長さとミュート | 音を伸ばすか、切るか | キックと重なる位置 |
| スライド・ゴーストノート | 表情を付ける細かい音 | ファンク寄りにするか |
| ピックと指弾き | アタックの硬さ | 太く丸い音か、硬い音か |
| シンセベースの音色 | 波形とフィルターの調整 | サブベースか、リフ系か |

### ドラム

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| ハットの開閉・オープンハット | Demo Composerに無い表情(オープンハットなど)を足す | ノリを作るポイントを決める |
| フィル・トム | セクションの終わりの細かいフレーズ | どこで入れるかを検討(Demo Composerでもできる) |
| スネア・キックの差し替え | 音色をジャンルに合わせる | 軽い音か、重い音か |

### ストリングス・ブラス

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| 奏法(レガート・スタッカート・トレモロ) | 音の切り方と、響き | 盛り上がりの場所で重ねるか |
| ダイナミクス | 音の強弱を、徐々に変える | 盛り上がり(サビで高い)と合わせる |

## 4. ボイシングとボイスリーディング

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| ボイシング | 和音の音の並べ方(転回形、開く・詰める、テンションの位置) | 和音の高さ、軽いか厚いか |
| ボイスリーディング | 和音から和音へ、共通音を保ち、最短で動かす | 上声部が滑らかにつながるようにする |
| 音域の配置 | 低音域の濁りに気をつけ、和音を中音域に置く | ベースと和音の対応 |
| 内声の動き | 和音の中の真ん中の音を、滑らかに動かす | テンションをどこに置くか |
| オンコード | ベースの音を変えて、ラインを作る | ベースラインの方向(下行・上行) |

Demo Composerは、1小節1コードで、和音の転回形やボイシングは細かく決められません。**コード名と度数までをDemo Composerで決め、並べ方はDAWで聴いて決める**という分担が自然です。

## 5. 音色の詳細

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| 音源選び | ピアノ、ギター、シンセなどのプラグインを選ぶ | Demo ComposerのSound(Lead・Pad・Keysなど)と方向タグ |
| シンセの設計 | 波形、フィルター、エンベロープ(ADSR)、LFO、ユニゾン | Bright・Soft・Airy・Warm・Dark・Aggressiveといった方向タグ |
| レイヤー | 複数の音色を重ねて厚みを作る | サビだけ重ねるか |
| アンプ・キャビネット | ギター・ベースの音の基礎を作る | 歪みの量 |
| 効果音・ライザー | リバースシンバル、インパクト、スイープ | セクションのつなぎのトランジション(ArrangeのTransition) |
| ドラム音源の差し替え | キック・スネアを好みの音に変える | ジャンルの方向性 |

## 6. ミックス

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| 音量バランス | 各パートの大きさを決める | 主役はボーカルか、リズムか |
| パン | 左右の位置を決める | 中央に置くパート(キック・ベース・ボーカル) |
| EQ | 不要な低域を削り、帯域を分ける | ベースとキックの低音の分担 |
| コンプレッサー・サイドチェイン | 音のばらつきを整え、キックでベースをへこませる | 勢いのあるポンピング感か、滑らかか |
| リバーブ・ディレイ | 空間の広がりを作る | 近さを出すか、広くするか |
| サチュレーション | 倍音を足して、太さを出す | 温かさ、太さ |
| ステレオ幅 | 広がりを調整する | サビで広げるか |
| オートメーション | セクションごとの盛り上がりを作る | 山谷(1枚目のシート)と合わせる |
| リファレンス曲との比較 | 音量・帯域を並べて確かめる | 参考曲のタブで決めた曲 |

## 7. マスタリング

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| 音量感(ラウドネス) | 全体の大きさを揃える | 配信先や、参考曲との比較 |
| リミッター | 音割れを防ぎつつ、大きくする | 押し出しの強さ |
| マスターEQ・コンプ | 全体のバランスを軽く整える | 明るさ、太さの方向 |
| 書き出し | 形式(WAV、MP3)、サンプルレート、ビット深度を決める | 公開先と、配信規格 |

## 8. 編集・つなぎ・その他

| 項目 | DAWでやること | 事前に決める方向 |
|---|---|---|
| MIDIのCC・ピッチベンド | モジュレーション、エクスプレッション、サステイン、ピッチの動き | どのパートに表情を付けるか |
| テンポ・拍子の変化 | テンポの揺れ、ラストでリタルダンド | 曲の終わり方 |
| アウトロ・フェード | 曲の終わりの処理 | 切るか、余韻で終わるか |
| トラック整理 | 名前、色、バス、グループを整える | パート一覧(Demo Composerの書き出しMIDI) |
| バージョン保存・バックアップ | 途中経過を残す | 保存のタイミング |
| ステム書き出し | パートごとの音声を書き出す | ミックスを人に任せるか |

## DAWへ渡す前の確認

- [ ] Song.midと、パートごとのMIDI(Chord / Melody / Bass / Drums / CounterMelody)を書き出した
- [ ] Hubの「Cubaseでやることメモ」を作った
- [ ] 音色の方向タグ(Soundタブ)を、メモに残した
- [ ] 「この曲でダメだと思う点」を、一言で書いておいた
- [ ] DAWでやる順番(音色 → ヒューマナイズ → ミックス → マスタリング)を確認した

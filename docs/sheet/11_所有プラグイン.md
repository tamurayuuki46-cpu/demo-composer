# 所有プラグイン

補助プラグインの一覧と、できることです。**差し替えて使う前提の下書き**です。自分が持っているものだけを残し、持っていないものは行ごと消してかまいません。

この表は、会話で聞いた名前と、Googleドライブにガイドがある名前から作りました。**所有**は、あなたの申告で「あり」にしました(「所有」列を、自分で直してください)。「できること」は、一般的な機能の説明で、細かいバージョン差は確認していません。

## 差し替えるときの手順

1. 持っていない行を、行ごと消す
2. 「所有」列を、持っているものだけ「あり」にして、自分の言葉で直す
3. 増やすときは、「(自分の)」の空欄の行に書く(Claudeに「所有プラグインに○○を足して」と頼むこともできます)
4. できることの欄は、自分が実際に使っている機能に書き換えてかまいません

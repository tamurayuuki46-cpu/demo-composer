# DAW移行後の流れ

Demo Composerで仮曲(Demo v1)を作ったあと、BandLabやCubasis、Cubaseでどう仕上げるかの、上流から順の流れです。上流(曲の骨格)から直し、下流(ミックス・マスタリング)は最後にします。

関連タブ:「DAWに任せる項目」(`10_DAWに任せる項目.md`)、「所有プラグイン」(`11_所有プラグイン.md`)、「アイデア帳」(`04_アイデア帳/`)、「いい曲チェック」(`09_いい曲チェック.md`)

## 流れの全体

1. Demo Composerから書き出す
2. DAWへ取り込む
3. Demoと同じに鳴るか確かめる
4. 音源を割り当てる
5. 演奏の表情(ヒューマナイズ)を付ける
6. 足りないパートを足す
7. ボーカルを入れる
8. ミックス
9. マスタリングと書き出し
10. 保存とバックアップ

## 1. Demo Composerから書き出す

- [ ] Song.mid と、パートごとのMIDI(Chord / Melody / Bass / Drums / CounterMelody)を書き出した
- [ ] project.json をバックアップとして書き出した
- [ ] Hubの「Cubaseでやることメモ」を作って、コピーした
- [ ] BPM、Key、構成(セクション名と小節数)を、メモに残した

## 2. DAWへ取り込む

- [ ] 新しいプロジェクトを作り、テンポと拍子(4/4)を、Demo Composerと同じにした
- [ ] Song.mid を読み込んだ(パートごとに分けたいときは、個別のMIDIを使う)
- [ ] トラック名を、Chord・Melody・Bass・Drums・裏メロにして、色を分けた
- [ ] BandLabの場合、MIDIを取り込めるかを、使う前に確認した(このドキュメントでは確認できていません)

## 3. Demoと同じに鳴るか確かめる

- [ ] コード・メロディ・ベース・ドラムが、Demo Composerと同じリズム・音になっている
- [ ] 構成のマーカー(セクション名)が、読み込まれている
- [ ] ドラムのマッピング(Kick=C1、Snare=D1、Closed HH=F#1)が、使うドラム音源と合っている
- [ ] ずれや欠けがあれば、この段階で直した(後で直すのは手間が増える)

## 4. 音源を割り当てる

Demo Composerの音色は仮の音で、方向タグ(Bright・Softなど)だけがメモに残っています。自分のプラグイン(「所有プラグイン」)を、次のように割り当てる案です。

| パート | 割り当ての案 |
|---|---|
| Chord | EZkeys 2、SampleTank 4、Scaler 3(演奏パターン) |
| Melody | Serum 2、SampleTank 4、Synthesizer V(歌にする場合) |
| Bass | EZbass、MODO BASS、SubLab(サブベースを足す) |
| Drums | EZdrummer 3、MODO DRUM、XO(音の差し替え) |
| Guitar | Ample Guitar、AmpliTube 5 |
| 上モノ・ストリングス | Syntronik、Miroslav Philharmonik 2、Serum 2 |

この割り当ては、こちらで用意した案です。聴いて、自分の好みで変えてかまいません。

- [ ] 各パートに、音源を割り当てた
- [ ] Demo Composerで決めた方向タグ(明るさ・柔らかさなど)に近い音色を選んだ

## 5. 演奏の表情(ヒューマナイズ)を付ける

- [ ] ベロシティの揺らぎ、タイミングのずれ、スウィングを、必要なところだけ付けた
- [ ] ゴーストノート、フィル、ハットの開閉を足した
- [ ] CC(モジュレーション・エクスプレッション)やピッチベンドを、表情を付けたいパートに入れた

- 詳しい項目は、「DAWに任せる項目」の「ヒューマナイズ」を見る

## 6. 足りないパートを足す

- [ ] 上モノ(パッド)やストリングスを、山谷に合わせて入れた
- [ ] レイヤーやハモリを、サビだけに入れた
- [ ] 音ネタ(リバースシンバル・ライザー・インパクト)で、セクションのつなぎを作った
- [ ] アイデア帳の引き出しから、試したいネタを選んでいる

## 7. ボーカルを入れる

- [ ] 歌詞とメロディを、ボーカロソフト(Synthesizer V など)に入れた
- [ ] ピッチ曲線、ブレス、子音のタイミングを調整した
- [ ] ハモリやコーラスを、必要なところに足した

## 8. ミックス

順番:音量バランス → パン → EQ → コンプ → 空間(リバーブ・ディレイ) → オートメーション

- [ ] 主役(ボーカルかメロディ)が、一番前にいる
- [ ] ベースとキックの低音がぶつかっていない
- [ ] 山谷の表どおりに、セクションごとの盛り上がりを作った
- [ ] 参考曲と並べて、音量と帯域を確かめた

- 詳しい項目は、「DAWに任せる項目」の「ミックス」を見る

## 9. マスタリングと書き出し

- [ ] 音量感(ラウドネス)を、配信先に合わせた
- [ ] リミッターで、音割れを防いだ
- [ ] 書き出し形式(WAV、MP3)と、サンプルレートを決めた
- [ ] スマホのスピーカーと、イヤホンの両方で、聴いて確かめた
- [ ] 書き出したあと、「いい曲チェック」で通して聴いた

## 10. 保存とバックアップ

- [ ] プロジェクトを、日付とバージョン名で保存した
- [ ] 書き出した音声と、ステム(パートごとの音声)を残した
- [ ] Demo Composerのproject.jsonと、Googleドライブにもバックアップした
- [ ] 次の曲のために、「この曲で試してよかったこと」を、一言メモした

## 詰まったとき

- リズムやコードが変だと感じた:理論チェックリストで、用語を点検する
- 音色が決まらない:方向タグに戻り、もう一度聴く
- 全体が地味:いい曲チェックの「山谷」「緊張と解決」を見る

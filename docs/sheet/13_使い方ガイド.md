# 使い方ガイド

このドキュメントは、Demo Composerで曲を作る前後に使う、作曲の資料集です。全部を使う必要はありません。迷ったら、いつでも「ここから始める」(`00_ここから始める.md`)に戻ります。

## 3つの使い方

1. 始めるとき:「ここから始める」だけを、上から順に進める
2. 詰まったとき:下の「タブ一覧」から、近いタブだけを開く
3. 作ったあと:「いい曲チェック」で弱い所を見つけ、「DAWに任せる項目」でDAWへ渡す準備をする

## タブ一覧

- 「ここから始める」:作曲の一本道(6ステップ)。最初に開く
- 「[Claude] 作曲シート(記入用)」:テーマ・場面・心情、山谷、パート別の参考を書く表
- 「テーマ・場面・心情」:テーマ・場面・心情の例を拾う
- 「キー早見表」:12個のKeyの大雑把なイメージ
- 「アイデア帳」:パート別の具体的なネタの引き出し(16個のサブタブ)
- 「参考アーティスト」:参考にするアーティストと、巨匠の一覧
- 「ジャンルリスト」:ジャンルの特徴とBPMの目安
- 「理論チェックリスト」:用語で曲を点検する(コード、メロディ、転調など)
- 「構成ストック」:曲の構成パターンを貯める
- 「いい曲チェック」:できあがった曲を聴いて、直す順番を決める
- 「DAWに任せる項目」:DAWでやることと、事前に決める方向

## 書き込みと編集

- 表のセルをタップして、そのまま入力できます
- チェックボックスは、タップして✓を付けます
- 行が足りないときは、表の最後の行で、行を追加します

## Claudeに頼むときの例

- 「アイデア帳のベースに、5個足して」
- 「構成ストックに、この曲の構成を追加して」
- 「テーマ・場面・心情の例を、夏の曲向けに増やして」
- 「いい曲チェックを、この曲で通して」(曲の説明を添える)
- 「ここから始めるの順で、今日の曲を一緒に進めて」

## 注意

- 曲名・BPMの目安・理論の説明は、主にClaudeの知識から作ったものです。聴いて確かめてください
- Demo Composerとは、データではつながっていません。選んだ内容は、手でアプリに入れます
- スマホでは、サブタブの開閉の見え方が、パソコンと違うことがあります。見つからないときは、「アイデア帳」の一覧から開きます
- Googleドライブにあるコピーは、古い場合があります。最新は、このドキュメントです
